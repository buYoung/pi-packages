## [0.2.0] - 2026-10-28

### 새로워진 것

- `/redact`가 가림 상태, 사용 중인 설정, 이 세션의 건수를 보여 주고, 현재 세션이나 전역 기본값으로 가림을 켜고 끕니다. 가림을 끈 동안 Pi 상태 표시줄에 `redact off`가 보이며, 되쓰기 차단은 계속 `{{REDACTED}}`를 막습니다.
- `/redact-custom`이 전역 설정이나 신뢰한 프로젝트 설정에서 기본 규칙, 개인정보 엔티티, 필드 이름, 패턴, 예외를 편집합니다. 바꿀 때마다 저장하고 바로 적용하며, 입력한 한 줄을 가려 보는 미리보기가 있습니다. 터미널이 없으면 Pi 편집기 대화상자에서 설정 JSON을 편집합니다.
- `/redact-analytics`가 가린 내용을 나열하고, 각 기록의 원래 줄과 가린 줄을 diff나 전·후 보기로 보여 줍니다. 기록은 agent 디렉터리의 `analytics.sqlite`에 30일 동안 보관하며 원래 값이 들어 있습니다.
- 전역 설정 파일에 `enabled`와 `disabledRules`를 쓸 수 있습니다. pi-redact 0.1.x는 이 키가 든 파일을 건너뜁니다.

### 해결된 것

- `pi --mode json` 출력이나 RPC 클라이언트 같은 이벤트 수신자에게 가는 `read` 결과 사본도 본문처럼 파일 경로를 반영해 가립니다. 이전에는 `.env`, `.ini`, `.properties`, `.cfg` 파일에서 공백이 든 값의 첫 단어 뒤 부분이 그 사본에 남았습니다(예: `DB_PASSWORD={{REDACTED}} db pass`). 모델과 세션 파일에는 영향이 없었습니다.

### 제거된 것

- `/pi-redact`. 같은 상태를 `/redact`가 보여 줍니다.

## [0.1.0] - 2026-10-21

### 새로워진 것

- 도구 결과를 Pi가 저장하거나 보여 주기 전에 가립니다. details와 구조화된 결과도 포함합니다.
- 모든 모델 요청, 압축, 브랜치 요약을 보내기 직전에 가립니다. 다른 확장이 추가한 텍스트도 포함합니다.
- 가린 값은 줄마다 항상 `{{REDACTED}}`로 표시하고, 이 표식을 파일이나 명령에 쓰는 호출은 차단합니다.
- 전역 설정과 신뢰한 프로젝트 설정으로 필드, 규칙, 예외, 개인정보 엔티티를 추가하고, `/pi-redact`로 설정과 세션별 건수를 확인합니다.
