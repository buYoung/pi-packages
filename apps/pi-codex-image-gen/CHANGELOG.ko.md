- README에 성공한 결과가 인라인 이미지를 지원하는 터미널과 지원하지 않는 터미널에서 각각 어떻게 보이는지, 로컬 참조 경로가 `~/`로 시작해도 된다는 점을 적었습니다.

## [0.3.0] - 2026-10-21

### 새로워진 것

- `image_gen` 호출이 모델용 경로 안내 대신 작업 종류, 이미지 크기, 저장 경로를 간단히 보여 줍니다. 경로를 클릭하면 기본 앱으로 이미지를 엽니다.
- 생성된 이미지를 클릭하면 터미널 높이에 맞게 확대되고, 다시 클릭하면 원래 크기로 돌아갑니다. Pi 기본 fullscreen 모드에서 이미지마다 따로 확대됩니다.

### 달라진 것

- 번들 `imagegen` 스킬이 서로 독립적인 이미지는 한 응답에서 함께 요청해 병렬로 생성할 수 있다고 모델에게 안내합니다.
- 큰 백엔드 응답에 상한을 두어 과도한 오류 내용이 대화를 채우지 않게 했습니다.
- 로컬 참조를 읽을 때 취소를 반영하고 디렉터리·파이프·장치 경로를 거부합니다.
- 비어 있거나 잘못된 이미지 데이터는 오류로 반환하며, 큰 정상 이미지의 저장이 조용히 실패하던 문제를 고쳤습니다. 로컬 저장 실패는 여전히 이미지 반환을 막지 않습니다.
- 생성 이미지의 보관 위치와 수동 정리 방법을 안내합니다.
