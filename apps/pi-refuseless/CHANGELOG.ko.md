## [0.1.0] - 2026-10-28

### 새로워진 것

- Pi의 `/login`에 Refuseless가 API 키 공급자로 나옵니다. `/model`에는 그 키로 Refuseless가 돌려주는 모델이 모두 컨텍스트 크기·생각 수준과 함께 나오며, Pi는 로그인 직후와 `/model`을 열 때 모델 목록을 새로 받습니다. 요청에는 모델이 지원하는 생각 수준만 씁니다. 아직 생각 수준이 정해지지 않은 세션에서 모델을 고르면 `off` 대신 그 모델의 기본 생각 수준으로 시작합니다.
- Refuseless 모델을 쓰는 동안 대화형 Pi의 상태 줄에 새 요청이 쓸 수 있는 크레딧이 나오며, 응답이 끝날 때마다 새로 읽습니다. `/pi-refuseless`는 쓸 수 있는 금액, 잔액, 잡아 둔 금액, 키 한도를 보여 주고 상태 줄 표시를 켜고 끕니다. 이 설정은 Pi 에이전트 폴더의 `refuseless.json`에 저장됩니다. 잔액을 읽을 때는 크레딧이 들지 않습니다.
- 모델마다 Refuseless가 알려 주는 `abliterated` 값을 함께 저장하고 `cli models`에 보여 줍니다. abliterated 모델은 모델 ID 대신 이 값으로 구분합니다.
