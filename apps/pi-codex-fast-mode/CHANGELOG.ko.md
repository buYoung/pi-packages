## [0.5.0] - 2026-10-28

### 새로워진 것

- Codex CLI처럼 OpenAI Codex 모델 카탈로그로 Fast·Ultrafast 지원 여부를 정합니다. 이제 `gpt-6.1-terra` 같은 모델을 확장 업데이트 없이 선택할 수 있습니다. 카탈로그는 세션을 시작할 때 Pi의 `openai-codex` 로그인으로, 없으면 `openai` 공급자의 로그인으로 받습니다. 받은 속도 등급은 저장해 두 조회가 모두 안 될 때 쓰고, 카탈로그에 없는 모델과, 조회도 저장된 등급도 없는 세션은 내장 목록을 씁니다.
- 세션을 시작하고 카탈로그를 받는 동안 첫 요청과 `/codex-fast` 명령은 최대 5초 기다립니다. 그래서 내장 목록이 아니라 카탈로그의 속도 등급을 사용합니다.
- `--offline`이나 `PI_OFFLINE`을 쓰면 카탈로그를 조회하지 않고 `<agentDir>/codex-fast-mode/service-tiers.json`에 저장된 속도 등급을 사용합니다.

## [0.4.0] - 2026-10-21

### 새로워진 것

- 모델 목록 정렬 안내를 실제 설정 화면과 일치시켰습니다.
