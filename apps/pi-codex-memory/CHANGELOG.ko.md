## [0.2.0] - 2026-11-10

### 새로워진 것

- `/codex-memory`의 **Memory model**과 **Summary model**에서 모델을 고른 뒤 추론 강도를 고릅니다. **Default**나 그 모델이 제공하는 강도 중 하나를 고를 수 있고, 각 행에는 실제로 쓰는 강도가 `· high`처럼 함께 나옵니다.

### 달라진 것

- 이제 **Use current Pi model**은 Pi 세션의 추론 강도도 따르며, 모델이 그 강도를 제공하지 않으면 가장 가까운 강도를 씁니다. 이전에는 항상 기억 생성에 `low`, 요약에 `medium`을 썼습니다. 세션에서 추론을 끄면 기억도 추론 없이 만듭니다.
- 추론 강도만 바꿀 때는 대화 전송 동의를 다시 묻지 않습니다. 모델을 바꾸면 지금처럼 묻습니다.
- 이제 요청과 함께 전달된 요약에 나온 `thread_id`를 답에서 인용하면 그 기억을 사용한 것으로 칩니다. 요약으로만 쓰인 기억도 쓰지 않은 기억으로 지워지지 않으며, 이 인용도 상태 표시줄의 `cited`에 셉니다.

### 해결된 것

- 이미 쓰는 모델을 다시 골라도 설정한 추론 강도가 지워지지 않고, 강도를 설정한 모델이어도 모델 목록을 열면 그 모델에 커서가 놓입니다.
- **Delete unused memories after**로 지우는 기억이 더 이상 요약을 비우지 않습니다. 다음 요약 갱신에서 그 기억만 뒷받침하던 내용을 빼고, 갱신이 성공한 뒤 기억을 지웁니다.

## [0.1.0] - 2026-10-28

### 새로워진 것

- Pi 대화에서 결정과 맥락을 기억으로 추출·통합하고, 다음 세션에서 출처를 인용해 꺼내 씁니다. 켜기, 모델·범위, 저장된 기억은 `/codex-memory`, 시간·한도는 `/codex-memory-settings`에서 다룹니다.
- 기억은 꺼진 상태로 시작하며, 켤 때 마스킹한 대화 사본의 전송을 허용해야 합니다. 기억 생성과 요약은 각각 현재 Pi 모델이나 `/scoped-models`에서 고른 모델을 씁니다.
- 닫은 대화를 백그라운드에서 기억으로 만듭니다. 범위마다 열려 있는 Pi 세션 하나가 한 번에 최대 8개 대화를 처리하고, 그 세션이 닫히면 열려 있는 다른 세션이 이어받습니다. 기본값으로는 마지막 메시지 뒤 2시간이 지난 대화가 기억이 되고, 요약은 최대 2시간에 한 번 갱신하며, 최근 7일 안의 대화를 씁니다. `/codex-memory`의 **Create memories now**로 기다리지 않고 바로 실행할 수 있고, 진행 중인 작업은 같은 범위의 모든 세션 상태 표시줄에 나타납니다.
- 모델 호출 없이 기억을 고치거나 잊을 수 있고, 잊은 대화에서는 기억을 다시 만들지 않습니다. 에이전트에게 기억해 달라고 요청하면 확인을 받은 뒤 그 내용을 저장합니다.
- 같은 Git 저장소의 하위 폴더와 worktree가 기억을 공유합니다. 다른 저장소의 기억은 요청마다 확인하거나 한 방향 접근을 저장해 읽습니다.
- 대화를 압축해도 원래 사용자 발언을 추출 입력으로 씁니다.
- `@buyong/pi-codex` 번들에 포함됩니다.
